# PitStop

A social map app for discovering places in Vietnam.

## Quick Start

```bash
# Backend
docker-compose up -d

# Mobile
cd mobile
flutter pub get
flutter run
```

## Structure

```
├── mobile/      # Flutter app
├── backend/     # FastAPI backend
├── docs/        # Documentation
└── infra/       # Docker configs
```

See [mobile/README.md](mobile/README.md) and [backend/README.md](backend/README.md) for details.
